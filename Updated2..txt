## ⚡ Executive Summary
**DeFi Generacy** is an ultra-lightweight, high-performance forensic state auditor for the Solana blockchain. By parsing account discriminators, program-derived addresses (PDAs), and account flags directly from public ledger state, DeFi Generacy reveals:
- **Dormant Rent:** SOL trapped in abandoned program accounts, expired session keys, or closed positions.
- **Protocol State:** Historical flash-loan loops (e.g., MarginFi v2 automated sweeps), zero-size perp collateral accounts (e.g., Jupiter Perps), and closed program bytecode (e.g., legacy Ape Pro vaults).
- **Extreme RPC Efficiency:** Designed from day one to operate within developer free-tier constraints (e.g., Alchemy), reducing Compute Units (CUs) by up to 90% via batched `getMultipleAccounts` requests and deterministic client-side caching.

---

## 🛡️ Privacy & Security Manifesto: 100% Read-Only
- **Zero Wallet Connection:** No `wallet-adapter` scripts, no private keys, and no transaction signing prompts.
- **Zero Drainer Vulnerability:** By eliminating transaction signing entirely, users have zero risk of rogue approvals, signature manipulation, or malicious balance sweeps.
- **Public Ledger Transparency:** Uses public base58 public keys to execute read-only RPC calls (`getAccountInfo`, `getMultipleAccounts`).

## 📊 RPC Optimization & Alchemy Telemetry
Standard multi-protocol audits exhaust free-tier RPCs within minutes. DeFi Generacy solves this via:
- **Algorithmic PDA Calculation:** Addresses are derived client-side before network dispatch.
- **Batching:** Querying 100+ protocol PDAs in 100-key chunks using `getMultipleAccounts`.
- **Telemetry Benchmark:** Decreases per-audit Compute Units from ~120 CUs down to ~12 CUs (~90% overhead reduction).
